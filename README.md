### 🧠 TanyaSalman AI Platform

**[TanyaSalman AI](https://tanyasalman.com)** is an AI chatbot platform designed to help users with daily questions, learning, writing, productivity, and coding assistance.

Key features:

- 💬 **AI Chatbot Assistant**  
  Helps users ask questions, create content ideas, summarize materials, improve writing, and solve daily tasks.

- 🧠 **Multiple AI Modes**  
  - **Salman V1 Thinking**: suitable for general use and daily questions  
  - **Salman V1 Pro**: optimized for faster and more productive responses  
  - **Salman V1 Ultra**: designed for more detailed answers, technical analysis, and coding assistance  

- 💻 **Coding Assistance**  
  Salman V1 Ultra can help with writing code, debugging errors, understanding scripts, creating project structures, and explaining technical solutions.

- 👤 **User Account System**  
  Includes login, registration, user plans, usage limits, and chat history.

- 💳 **Premium Plan System**  
  Supports Free, Premium Pro, and Premium Ultra plans with controlled usage limits.

- 🔐 **Security-Focused System**  
  Built with native PHP, MySQL/MariaDB, PDO prepared statements, CSRF protection, secure password hashing, and private backend configuration.

### ✨ EditorSuper AI Platform

**[EditorSuper AI](https://www.editorsuper.com)** is an all-in-one browser-based web app for PDF and image editing powered by advanced AI.

Features:

- 🔧 **PDF Utilities**  
  Compress, merge, split, convert PDF to Word/JPG, rotate pages, add page numbers, and add watermark.

- 🖼️ **Image Tools**  
  Resize, crop, format conversion, background removal and replacement, upscale, and face swap.

- 🔒 **Privacy First**  
  100% client-side processing — no file uploads to servers.

- ⚡ **Lightning-Fast**  
  Real-time previews and lightweight UI built with JavaScript and WebAssembly.

- 💡 **Hand-crafted**  
  Developed from scratch by the founder without heavy external dependencies.
